Deadpan Forecasts for Cities That Do Not Exist — a single-line weather
forecast for the fictional city of Glimmerwick, written to be read aloud
by a straight-faced TV meteorologist.

## The entry

> In Glimmerwick, a high of 61 with light confetti drizzle, clearing to
> scattered applause by evening, low of 48, and a 20 percent chance of an
> encore.

149 characters. Every forecast element is real broadcast vocabulary
(high, drizzle, clearing, scattered, low, percent chance) — only the
weather itself is absurd: confetti drizzle, scattered applause, and a
chance of an encore.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: it writes the same bytes on every run.
